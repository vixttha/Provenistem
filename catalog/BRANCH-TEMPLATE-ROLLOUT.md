# Provenistem on reusable template branches

Provenistem is the shared Ideas and Features tracker. Each permanent template branch carries a local library for that workspace. The Lydite Test Vault retains its own tests, test catalog and receipts, while Provenistem records ideas and features for Lydite just as it does for other templates.

For a new library, use the [portable Provenistem v0.0.2 package](https://github.com/vixttha/Provenistem/tree/e36fcd6d12633395e9b573228c0797ade9e775b0/packages/provenistem). Add it under `provenistem/` on the template branch, keep the MIT notice, and start with empty `ideas/records/` and `features/records/`. Record the exact source pin and target branch in `provenistem/INSTALLATION.md`. Human and agent users can browse the catalog and its instructions on GitHub. The optional validator checks the records and indexes.

Reuse a branch’s existing catalog where it already exists. When an adopter or repo-wide catalog owns a record, link to that pinned record from the template instead of creating a competing source. Use the actual template branch as the target for adoption review. Publish approved product outputs through their own reviewed product PR.

## Existing catalogs and scope boundaries

- [Lydite's populated catalog draft](https://github.com/vixttha/Lydite-Test-Vault-Template/pull/116) retains its 10 Ideas, 12 Features and branch audit for the Vault project.
- [README HQ's existing catalog](https://github.com/vixttha/README-HQ/tree/Provenistem), [Veraphify's existing catalog](https://github.com/vixttha/Veraphify/tree/Provenistem), [Brand Identity's existing catalog](https://github.com/vixttha/Brand-Identity-Template/tree/provenistem) and [Version Issues Hub's existing catalog](https://github.com/vixttha/Version-Issues-Hub/tree/Provenistem) continue as project-owned sources.
- Archived versions and legacy compatibility refs preserve their original source and receipts. Governance’s existing Ideas and Features remain under its [optional module boundary](https://github.com/vixttha/Provenistem/blob/e36fcd6d12633395e9b573228c0797ade9e775b0/packages/provenistem/docs/ONE-WAY-BOUNDARY.md).
- The dedicated library run checks structure and index freshness. [Lydite #121](https://github.com/vixttha/Lydite-Test-Vault-Template/issues/121) tracks duplicate-member detection for populated records.
